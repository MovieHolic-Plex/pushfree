Phone screenshots go here.

fastlane/F-Droid expects PNG/JPEG screenshots named like:
  1_en-US.png, 2_en-US.png, ... (or .jpeg)

These are PLACEHOLDER slots only — capture real screenshots from a release
build (subscribe to a server, send a priority-2 emergency message, open the
message detail screen, show the settings screen) before a store/F-Droid
listing submission. Recommended: 1080x1920 to 1440x3120, 2-8 images.

Do not commit blank/empty files; leave this directory empty (this README is
the only tracked file) until real screenshots exist.
